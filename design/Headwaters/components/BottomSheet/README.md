A bottom sheet that holds the river panel on mobile, with three heights: peek, half and full.

Provide `children`, a `title` for assistive tech, and `defaultState` or `state` with `onStateChange`. `heights` overrides the defaults.

- Peek shows only the river name and the one key figure, so the map stays visible.
- The handle is a button. Do not make dragging the only way to change height.
