Inline stroke icons on a 24px grid, drawn at 1.75px with round caps, for controls and map markers.

Provide `name` from `Icon.names`. Pass `title` only when the icon stands alone and carries meaning; otherwise it is hidden from assistive tech.

- Pair every icon that carries status (check, alert, error, info) with a word.
- Use `source`, `mouth` and `area` for the three core map ideas; do not reuse them decoratively.
- Do not add wave, droplet or swoosh icons. Rivers are branches, not ripples.
