Map markers with different shapes: a ringed circle for a source, a diamond for a destination and a crosshair for the selected point.

Provide `kind`, and optionally `name`, `coordinates` and `size`. With no `name` it renders only the SVG; add `label` so it has an accessible name.

- Coordinates in previews are samples.
- Do not recolour markers per river. The shape and the accent colour mean the same thing everywhere.
